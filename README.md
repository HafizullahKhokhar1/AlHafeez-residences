# AlHafeez Residences

Responsive, static residence website with a small JavaScript enhancement for the scroll-linked tower gallery and enquiry form.

## Content and assets

- Update page copy in the corresponding `.html` file.
- Update shared styling in `css/style.css`.
- Tower gallery scroll and enquiry-mail handling are in `js/site.js`.
- Replace images in `images/` while preserving the filenames referenced by the pages.
- Shared brand and contact details for generated pages are in `build/generate.py`.

The enquiry form opens the visitor's email application with the completed message addressed to AlHafeez. For server-side submissions, connect a form provider or backend before deployment.

## Build

Run `python build\generate.py` from this directory to generate a site in the `alhafeez-website` output folder.
